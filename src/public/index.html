Permintaan Maps API (JavaScript) 
import axios from "axios";

const maps = axios.create({
  baseURL: "https://api.Truenapsh.io/v1/maps",
  headers: {
    "x-api-key": process.env.Truenapsh_API_KEY,
  },
});

// Cari koordinat dari alamat
const result = await maps.get("/geocode", {
  params: {
    address: "Jl. Sudirman, Jakarta",
    country: "ID",
  },
});

Dari skema ke endpoint hanya dalam hitungan menit.

Buat database, definisikan tabel, dan dapatkan endpoint API otomatis tanpa konfigurasi manual.

1

Buat Project & Skema

Tentukan nama project, region, dan definisikan tabel lewat UI atau file skema. 

table ongkir_request {
  id          uuid primary key,
  origin      text not null,
  destination text not null,
  weight_gram int  not null,
  courier     text,
  created_at  timestamptz default now()
}
2

Dapatkan Kunci API

Buat API key terpisah untuk Maps, HumData, dan Cek Ongkir sesuai kebutuhan integrasi Anda.

Maps public key

nd_maps_pub_8dK2...pQ1z

3

Integrasikan di Kode

Pakai HTTP client favorit atau SDK siap pakai untuk Cek Ongkir dan HumData dalam satu project. 

curl -X POST https://api.Truenapsh.io/v1/cek-ongkir \
  -H "x-api-key: <API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{
    "origin": "JKT",
    "destination": "SBY",
    "weight_gram": 1200,
    "courier": ["jne", "pos"]
  }'
